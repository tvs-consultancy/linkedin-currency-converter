# Currency Converter UI Design

**Date:** 2026-02-16
**Purpose:** Add a web UI to showcase the existing currency converter API as a portfolio/demo piece
**Approach:** Monorepo with Next.js frontend deployed to Cloudflare Pages

---

## Overview

Add a minimal, fully responsive web interface for the currency converter API. The UI will be built with Next.js, use Tailwind CSS for styling, and deploy to Cloudflare Pages. The project will be restructured as a monorepo to enable type sharing between the API and UI.

**Primary goals:**
- Showcase the API with a clean, professional interface
- Demonstrate modern web development practices (Next.js, TypeScript, monorepo)
- Maintain simplicity - focus on core conversion functionality
- Ensure fully responsive design (mobile, tablet, desktop)

### Deployment Strategy

- **API**: Cloudflare Workers (existing setup, no changes to deployment)
- **Web**: Cloudflare Pages via \`npx wrangler pages deploy\`
- **CI/CD**: Single GitHub Actions workflow deploys both on push to main
- **Type sharing**: Web package imports types from \`@repo/api\` workspace reference

### Local Development

- API runs on \`http://localhost:8787\` via \`npm run dev -w packages/api\`
- Web runs on \`http://localhost:3000\` via \`npm run dev -w packages/web\`
- Development Next.js app calls local Worker
- Production Next.js app calls deployed Worker URL

## Data Flow

### Page Load
1. Next.js renders home page with CurrencyConverter component
2. Component fetches available currencies from new \`/currencies\` API endpoint
3. Populates "From" and "To" dropdowns with currency codes

### Currency Conversion
1. User enters amount, selects currencies, clicks "Convert"
2. Client-side validation:
   - Amount must be > 0
   - From and To must be different currencies
3. Makes API call: \`GET /convert?amount=100&from=USD&to=EUR\`
4. Shows loading state (spinner/disabled button)
5. On success: Displays \`convertedAmount\`, \`rate\`, \`description\`
6. On error: Displays user-friendly error message

### State Management
- React \`useState\` for form inputs, results, loading, errors
- React \`useEffect\` or Server Components for initial currency list fetch
- No complex state library needed (Redux/Zustand) - simple enough for local state

### API Client
- Wrapper function in \`src/lib/api.ts\`
- Environment-based URL switching (localhost vs production)
- Type-safe using types imported from \`@repo/api\`

## Error Handling

### UI-Level Validation
- Amount > 0 (inline error message)
- From and To currencies selected (disable button until valid)
- From ≠ To (show error if same)
- Clear, user-friendly messages

### API Error Handling
- **Network errors:** "Unable to connect. Please try again."
- **400 errors:** Display API error message
- **404 errors:** "Service not found. Please refresh the page."
- **500 errors:** "Something went wrong. Please try again later."
- Errors display in red alert box below form
- Errors clear when starting new conversion

### Loading States
- Show spinner/loading text on Convert button
- Disable form inputs during API call
- Prevent duplicate submissions
- Clear previous results when starting new conversion

### Edge Cases
- \`/currencies\` endpoint fails: Show error with retry option
- User offline: Friendly offline message
- Very large numbers: Let API validation handle
- Invalid currency codes: API validates and returns error
